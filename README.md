# Proyecto Integrador de Aprendizaje Automático: Visión Artificial para Seguridad, Logística y Operaciones Inteligentes

Este repositorio contiene la solución completa para el Proyecto Integrador de Aprendizaje Automático enfocado en la unidad de **Visión Artificial**.

## Proyecto Seleccionado: Proyecto 1 - Monitoreo de Elementos de Protección Personal (EPP)

El objetivo principal de este proyecto es diseñar, desarrollar e implementar un sistema de visión artificial capaz de detectar automáticamente el uso (o ausencia) de los siguientes Elementos de Protección Personal (EPP) en entornos industriales, portuarios y logísticos:
- Casco de seguridad
- Chaleco reflectante
- Lentes de seguridad
- Guantes de protección

## Estructura del Proyecto

* **`main.pdf`**: Guía y especificaciones oficiales del proyecto integrador.
* **`informe_tecnico(Hito1).md`**: Reporte técnico que cubre el **Hito 1: Definición del Problema** (Contexto organizacional, Problema a resolver, Impacto esperado, Objetivo general y Objetivos específicos).
